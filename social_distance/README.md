# Social distancing analysis

This directory contains the code, derived datasets, model outputs, and figures
used to analyse predictors of social distancing behaviour in Australia before
and after state-level face mask mandates.

## Structure

- `analysis/`: exploratory analysis and feature-importance generation scripts
- `code/`: data preparation and modelling pipelines
- `data/`: cleaned, split, and model-ready datasets
- `figures/`: exploratory figures
- `R/`: R scripts and feature-importance figures
- `results/`: fitted models, validation summaries, and test results
- `raw_data/`: instructions for obtaining the source datasets

Run scripts from the project directory so that their relative paths resolve
correctly. The numbered scripts in `code/` describe the main processing order.
